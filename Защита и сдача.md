# 02-02 · WPF DataBinding — Учёт услуг

Модестов Константин Кириллович, ПР-31, вариант 10.

## Как запустить

В Visual Studio 2022 с компонентом «Разработка классических приложений .NET» открой `02-02-DataBinding-Modestov.sln` и нажми **F5**. Для терминала на Windows с .NET 8 SDK открой папку проекта и выполни `dotnet run --project ServiceApp.csproj`. На этом компьютере SDK также можно вызвать командой `& 'D:/Development/Tools/dotnet8/dotnet.exe' run --project ServiceApp.csproj`.

## Что показать преподавателю

1. Заполни название «Настройка принтера», исполнитель «Иванов», цена 800, часы 2. Сумма сразу станет 1 600 ₽.
2. Сохрани запись и запиши её ID. Нажми «Новая запись». Поля очистятся, а ID изменится.
3. Введи старый ID в поиск. Карточка должна загрузиться. Измени часы на 3, сохрани и снова найди запись.
4. Попробуй поискать ID, которого нет. Покажи сообщение. Для проверки сохранения закрой и открой программу, затем снова найди сохранённый ID.

## Как устроен код

- **MainWindow.xaml** — поля, кнопки и привязки. `DataContext` окна — текущая услуга. Через `Binding` поле читает свойство модели и записывает в него введённое значение. `UpdateSourceTrigger=PropertyChanged` обновляет модель во время ввода.
- **Service.cs** — модель. `Total` умножает цену на часы. Сеттеры `Rate` и `Hours` посылают событие `PropertyChanged` и для своего свойства, и для `Total`. По этому событию WPF перечитывает итог.
- **MainWindow.xaml.cs** — сохранение, поиск и новая карточка. Целый ID выбирается случайно, существующие файлы проверяются. При первом сохранении файл создаётся без перезаписи. Если в этот момент ID занят, приложение берёт новый. При редактировании найденной записи её файл обновляется.
- Данные лежат в `%LOCALAPPDATA%\WpfService10`. Одна услуга — один файл `<ID>.json`. `JsonIgnore` у итога оставляет в файле только исходные данные.

## Что можно поменять на защите

- **Попросили показать сумму с наценкой 10%**. В `Service.cs` измени формулу `Total` на `Rate * Hours * 1.10m`. Суффикс `m` означает тип `decimal`. Для 800 и 2 получится 1 760 ₽. Обновление суммы продолжит работать через то же событие.
- **Попросили переименовать поле**. В `MainWindow.xaml` замени текст подписи «Исполнитель» на «Мастер». Свойство `Worker` можно оставить, привязка продолжит работать.

## Что сказать

«У меня карточка услуги. Поля в окне связаны со свойствами класса Service. При изменении часов модель сообщает WPF, что сумма поменялась. Каждая карточка сохраняется в отдельный JSON с ID в имени. Сейчас сохраню услугу, создам новую карточку и найду старую по ID».
